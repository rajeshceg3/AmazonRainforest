# Amazon Rainforest Immersive Experience

A serene, visually poetic interactive web experience inspired by restrained, emotionally intelligent design thinking.

## Vision
The experience invites users to gently wander through the Amazon Rainforest. Rendered as a living, breathing 3D world using Three.js, everything moves softly and nothing demands attention.

## Tech Stack
- **Framework**: React + Vite
- **Rendering**: Three.js (@react-three/fiber, @react-three/drei)
- **Styling**: Tailwind CSS v4
- **Animation**: GSAP and Three.js frame-based animation

## Features
- **Atmospheric Scene**: Deep forest lighting, humidity fog, and particle-based rain.
- **Organic Navigation**: Custom camera controller for slow, natural drift and sway.
- **Flora & Fauna**: Animated butterflies and forest creatures (placeholders).
- **Minimalist UI**: Subtle, poetic text overlays that fade in and out.

## Development
```bash
npm install
npm run dev
```
